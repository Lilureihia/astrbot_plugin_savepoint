## 💡 为什么需要《存档点》？

在长对话或复杂的角色扮演、辅助工作场景中，我们常常遇到以下痛点：
- **基础人设提示词越塞越长**：把所有外貌细节、临时场景、短期约定全写进主 System Prompt，导致大模型**注意力严重分散（Needle In A Haystack 衰减）**，核心人设反而容易崩坏。
- **自动长期记忆（RAG）不可控**：黑盒检索经常捞出过期或无关的历史对话片段，且无法按需绑定**当前视觉参考图**。

**《存档点 SavePoint》提供了一套像单机游戏“营地篝火存档”一样直观的手动上下文外设方案：**
1. **🏷️ 模块化 TAG 资产库**：将一张参考图、一段客观背景描述、一条核心 Prompt 约束封装为一个独立的 **TAG 节点**。
2. **🏕️ 复数 TAG 组装存档槽**：提供多个存档槽（Save Slots），每个槽位可从下拉菜单自由选入**复数个 TAG** 进行组合、排序，并支持**槽位间一键克隆复制**以尝试不同剧情或工作分支。
3. **🎯 单槽位纯净注入 & 零冲突**：全局仅加载当前点燃激活的**唯一存档槽**，在请求大模型前通过 `@filter.on_llm_request` 动态注入文本与多模态参考图，**绝不污染历史聊天数据库**，与市面上任何长期记忆/RAG 插件 100% 兼容共存。

## 🚀 三分钟快速上手指南

### 第一步：打开《存档点》可视化工作台
插件安装并启用后，支持以下两种方式进入管理面板：
1. **AstrBot 原生侧边栏入口（推荐）**：
   - 在 AstrBot 管理后台进入 **「插件」** 页面，找到 **「存档点 SavePoint」** 卡片；
   - 点击卡片底部的 **[🖥️ 打开视图]** 按钮，或点击 **[📌 图钉]** 按钮将其固定至左侧导航栏 **「扩展功能 -> 存档点」**，即可随时在侧边栏一键切换。
2. **独立端口直连**：
   - 在浏览器直接访问 `http://127.0.0.1:8765`（端口可在插件配置中修改）。

---

### 第二步：在右栏创建你的第一个【TAG 信息条目】
进入面板右侧的 **「🏷️ TAG 信息库编辑器」**：
1. 填写 **TAG 标识名称**（必填，如：`当前场景`、`外貌参考`、`回复规则`）；
2. *(可选)* 填写 **面板备注摘要**（如：`雨天室内版`，仅用于你在列表里区分版本，不会发给大模型）；
3. *(可选)* **拖拽或点击上传参考图片**（如角色当前穿搭图、场景草图、工作截图）；
4. *(可选)* 填写 **补充描述**（客观事实说明）与 **核心提示词框 Prompt**（需要模型遵守的指令要求）；
5. 点击底部橙色按钮 **「🔥 保存并立即挂入左侧当前槽位」**（或点击「💾 保存至 TAG 库」稍后手动挂载）。

---

### 第三步：在左栏组装【存档槽】并点燃激活
在面板左侧的 **「🏕️ 存档槽管理」**：
1. 点击选中你要配置的存档槽卡片（如 `存档槽 1`）；
2. 可通过 **「📦 往此存档槽挂载 TAG」** 下拉菜单，将多个不同的 TAG 组合挂载进同一个槽位，并用 `↑` `↓` 按钮调整它们的先后顺序；
3. 查看底部的 **「👁️ 实时注入预览」**，确认即将合成给大模型的内容无误；
4. 点击 **「🔥 点燃并激活此槽位」** —— 顶部状态栏亮起橙色呼吸灯，代表当前存档点已正式接管对话补充上下文！

> 💡 **分支试错小技巧**：想尝试新剧情但怕改坏现有组合？在左栏底部选择目标槽位（如 `存档槽 2`），点击 **「📋 复制到此槽」**，即可一键克隆全部已挂载 TAG，在新槽位里放心增删！

## 📋 WebUI 字段加载机制与作用说明表

为了让上下文保持极致精炼、不浪费任何多余 Token，《存档点》严格区分了 **「⚡ 会被加载至大模型」** 与 **「📌 仅面板管理备注」** 的字段：

| 所在区域 | 字段名称 | 是否加载至模型 | 具体作用与对大模型的影响范围 |
| :--- | :--- | :---: | :--- |
| **左栏 · 存档槽** | **槽位名称** | 📌 **不加载** | 仅用于在左侧列表区分不同存档槽（如“日常主线”“跑团分支”），零 Token 消耗。 |
| **左栏 · 存档槽** | **槽位全局说明** | ⚡ **会被加载** | *(选填)* 作为当前存档槽的整体大前提注入系统提示词，影响模型对当前对话总体情境的认知；留空则不注入。 |
| **右栏 · TAG 库** | **TAG 标识名称** | ⚡ **会被加载** | *(必填)* 作为注入条目的分类小标题（如 `1. 【当前场景】`），帮助大模型清晰锚定该段信息的维度。 |
| **右栏 · TAG 库** | **面板备注摘要** | 📌 **不加载** | *(选填)* 仅在下拉菜单与已挂载列表中显示（如标注“v2微调版”），方便用户管理，不发给大模型。 |
| **右栏 · TAG 库** | **参考图片上传** | ⚡ **会被加载** | *(选填)* 开启多模态注入后直接传入模型视觉通道（Vision），直接影响模型对外观、画面与物体细节的视觉感知。 |
| **右栏 · TAG 库** | **补充描述** | ⚡ **会被加载** | *(选填)* 作为客观背景事实与设定说明注入，影响模型对所处环境、参考图背景或事件前因后果的认知。 |
| **右栏 · TAG 库** | **核心提示词框** | ⚡ **会被加载** | *(选填)* 作为高优先级规则与指令注入系统提示词，直接影响模型的回复语气、状态演绎与行为边界。 |

## ⚙️ 插件设置与聊天指令

### 插件配置项（`_conf_schema.json`）
在 AstrBot 插件管理页点击 **「⚙️ 设置」** 可调整以下全局参数：
- **启用存档点注入 (`enable_plugin`)**：插件总开关，关闭后暂停一切上下文与图片注入。
- **WebUI 监听地址 (`webui_host`)**：默认 `127.0.0.1`；若部署在云服务器或 Docker 需外部直接访问可设为 `0.0.0.0`。
- **WebUI 监听端口 (`webui_port`)**：默认 `8765`。
- **多模态图片注入 (`inject_images`)**：默认开启。若当前使用的模型不支持视觉（Vision）能力，可关闭此项以仅注入文字。
- **文本注入位置 (`inject_position`)**：可选追加在系统提示词末尾（`tail`，默认推荐）或插入在头部（`head`）。

### 聊天端状态查询指令
- **`/sp_status`**：在任意聊天窗口发送该指令，即可快速查看当前点燃激活的存档槽名称、已挂载的 TAG 列表及附带的参考图片数量。

## 📂 数据存储与安全合规

本插件严格遵循 AstrBot 数据持久化规范，所有用户数据与图片均独立存放在宿主机标准数据目录下，更新或重载插件绝不丢失数据：
- 数据库文件：`data/plugin_data/astrbot_plugin_savepoint/savepoint_db.json`
- 参考图片目录：`data/plugin_data/astrbot_plugin_savepoint/images/`
